Variables and Data Types

Basic Data Types

Programming languages have different types of data:

  • Integer (int) - whole numbers
  • Float/Double - decimal numbers
  • String - text data
  • Boolean - true/false values
Remember: Always declare variables with appropriate data types for memory efficiency
// Example in Java int age = 25; String name = "John"; boolean isStudent = true;

Variable Naming Rules

Good practices for naming variables:

  • Use descriptive names
  • Start with a letter or underscore
  • Use camelCase for multiple words
  • Avoid reserved keywords

Quick Reference

Important Points to Remember

  • Always initialize variables before use
  • Use meaningful variable names
  • Comment your code for clarity
  • Test edge cases in conditional statements
